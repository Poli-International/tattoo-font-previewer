## What is Tattoo Font Previewer?

The Tattoo Font Previewer is a free, browser-based tool that lets you preview text in over 50 professional tattoo fonts before committing to ink. Built with React and optimized for both desktop and mobile, this tool renders your custom text in real-time across multiple font categories including blackletter, script, gothic, and decorative styles.

The tool provides a text input field, font category filter, adjustable font size (default 48px), and background color picker (default white). It supports dark mode and can be embedded on any website via an iframe. The tool is fully responsive and works on smartphones, tablets, and desktop computers.

## Who Should Use This

**Tattoo Artists:** Preview lettering designs for clients during consultations. Compare multiple font styles instantly to find the perfect match for the client's vision.

**Tattoo Clients:** Test how your name, quote, or phrase will look in different tattoo fonts before visiting the studio. Make informed decisions about your tattoo lettering.

**Studio Managers:** Embed the tool on your studio website to give clients a self-service preview option. Reduce consultation time by letting clients explore fonts beforehand.

**Tattoo Apprentices:** Learn about typography styles used in tattooing. Experiment with different font categories to understand how lettering works on skin.

## How to Use

1. **Enter your text:** Type your desired tattoo text into the text input field. The default text is "Tattoo Art" but you can replace it with any word or phrase.

2. **Choose a font category:** Use the category filter to narrow down fonts. Options include All, Blackletter, Script, Gothic, and Decorative. Selecting a category shows only fonts in that style.

3. **Adjust font size:** Use the font size control to set the preview size. The default is 48px. Increase or decrease to see how the text scales.

4. **Set background color:** Use the background color picker to simulate different skin tones or tattoo placement backgrounds. The default is white.

5. **Preview and compare:** The main preview area displays your text in all available fonts within the selected category. Scroll through to compare styles side by side.
