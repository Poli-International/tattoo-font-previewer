# Tattoo Font Previewer

Professional, real-time tattoo font previewer, lettering visualizer, and stencil transfer generator by Poli International.

## Features

- **107 Curated Tattoo Typefaces**: Blackletter, Script / Cursive, Chicano / Ornate, Fineline / Minimalist, Japanese (Kanji/Kana), Chinese (Hanzi), Gothic / Dark, and Decorative / Display styles.
- **Custom Local Font Loader**: Load private .ttf and .otf files directly into client browser memory for instant evaluation.
- **Precision Arc & Curve Bending**: Upward and downward arc controls for chest rockers, collarbones, and forearm lettering.
- **Thermal Stencil Transfer Mode**: Outline mode with selectable line weight (1pt, 2pt, 3pt) and thermal stencil purple, carbon blue, and carbon black hues.
- **Hardware DPI & Size Calculator**: Real physical dimensions in inches and millimetres calculated for 203 DPI and 300 DPI thermal stencil printers.
- **Side-by-Side A/B Comparison Dock**: Pin two fonts side-by-side to compare delicate flourishes and kerning balance.
- **High-Resolution Master Export**: Export up to 7200 x 2400 px master PNGs with transparent, dark, light, or simulated skin backgrounds.
- **Multi-Language Support**: Complete interface translation in 7 languages (English, German, Spanish, French, Italian, Portuguese, Dutch).
- **Zero Telemetry & 100% Client-Side**: All rendering and processing occurs strictly in your browser.

## Development & Build

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run TypeScript check
npm run lint
```
